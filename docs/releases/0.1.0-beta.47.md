# Fan4Compat 0.1.0-beta.47

Compatibility with the newest builds of three mods.

**Sound Physics Remastered 1.21.1-1.5.2 (fix).** 1.5.2 changed the last parameter of `SoundPhysics.evaluateEnvironment` and `setDefaultEnvironment` from a boolean to a float, so the portal sound
hook (sound through Immersive Portals portals and the cached ray casts) no longer matched and would not have applied. It now targets the 1.5.2 shape. **1.5.1 is no longer supported**: its method does not
exist in 1.5.2 and the hook can only match one of them. Everything else the hook uses in Sound Physics is unchanged.

**Xaero's Minimap 26.6.0 and World Map 1.47.0 (no code change).** The two updates only changed the minimap's cave-mode zoom and Open Parties and Claims support; none of the classes the TARDIS minimap, shared map and
waypoint sync hook or call changed. The Xaero features now accept **26.6.0 / 1.47.0 and the earlier 26.5.0 / 1.46.0**, so a server or client that has not updated keeps working. Other builds still switch the Xaero hooks off, with a
startup warning that names the supported ones.

Validation: clean build, all tests (new: the accepted and rejected Xaero builds), and the full set of real-jar checks run against the jars of the current pack (Valkyrien Skies, Immersive Portals, Doctor Who Mod 1.0.39, Sound Physics 1.5.2,
BCLib, Aether, Distant Horizons, Iris, Point Blank, Accessories, Xaero 26.6.0 / 1.47.0, YACL 3.8.2, Mod Menu 11.0.5). The Xaero checks also pass on 26.5.0 / 1.46.0. Not run in game.
