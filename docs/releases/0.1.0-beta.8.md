# Fan4Compat 0.1.0-beta.8

Candidate fix for DH terrain disappearing near Freecam after beta 7 allowed the
camera to move beyond full chunk coverage. DH's nearby-terrain exclusion expects
Minecraft terrain to replace the LODs, leaving holes when no full chunks exist.

For the active FreeCamera in an unloaded full-terrain chunk, cap DH's near plane at
0.5 blocks and set its native GL terrain clip uniform to zero. Loaded terrain,
normal player views, foreign worlds and portal draws keep native clipping. The
native shader restores its own uniform each frame. No global setting, shader
source or terrain-generation behavior changes.

Exact supported Freecam/DH versions are unchanged: internal Freecam 1.3.0+mc1.21
and DH 3.3.3. The original beta 7 tick fix remains. Destination portal LOD work is
paused; its isolated CPU prototype is excluded from the addon jar.

Validation: clean build, native DH/Minecraft selector and uniform checks, active
camera identity/terrain/world/portal gates, smaller near-plane preservation and
native clipping restoration. In-game validation remains pending, including Iris/BSL:
approach distant LODs, back away, return to loaded terrain and disable Freecam.
