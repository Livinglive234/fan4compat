# Fan4Compat 0.1.0-beta.30

Corrects beta 29 diagnostics using a legacy stencil-bits query invalid in Mac core
OpenGL. It could leave INVALID_ENUM for Xaero to detect and crash. Snapshots now
query attached stencil-image size through the core framebuffer attachment API;
the default framebuffer is left unqueried. No GL errors are drained or suppressed.

XM3 disappearance remains unresolved. Restart with
`-Dfan4compat.renderDiagnostics=true` and draw/unequip/redraw XM3 promptly after
joining, within the 45-second trace window. Include the full launch log.

Clean build and native binding checks validate packaging and hooks. Mac runtime
verification is still required. Release remains a draft.
