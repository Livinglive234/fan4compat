# Fan4Compat 0.1.0-beta.6

Cleanup of the supported feature set. Removes temporary movement observers,
diagnostic logging and an unused collision-query passthrough. Keeps native ship
load recovery, landing, player transit, door-face collision clipping and the
working DH/Iris shader guard. No gameplay dependency has been added.

Doorway chunk preparation remains because exits can otherwise hit the native
unloaded-ship movement guard. Rendering an exterior ship through newly reopened
portals remains on the wishlist; no separate preview implementation is retained.

Validation: clean build, bytecode verification, optional-mod gates, feature-link
audit and existing regressions. Repeat moving-ship crossings in game after updating.
