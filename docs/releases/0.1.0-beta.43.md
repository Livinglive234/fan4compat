# Fan4Compat 0.1.0-beta.43

**Valkyrien Skies save message.** Valkyrien Skies logs "ShipSavedData.save(): pipeline bytes = N KB" at INFO on every world save, which fills the console on a server.
Fan4Compat now hides that one message with a log4j filter on the root logger config (nothing else Valkyrien Skies or any other mod logs is touched). A new switch in the
Troubleshooting list, **Valkyrien Skies save logging** (`shipSaveLogging`, off by default, restart to change), works like the Eureka ship debug logging one: off hides the message, on
shows it again. If the filter cannot be installed, one warning is logged and the message stays.

Validation: clean build, all tests (new: the filter against real log4j 2.22.1 for the event, string, message and object forms, other messages untouched, and installation on the root logger),
the packaging check, and the real-jar native checks. log4j is a test-only dependency (its checksums are in `gradle/verification-metadata.xml`, compared with Maven Central); the jar bundles none.
Not run on a real server.
