# Fan4Compat 0.1.0-beta.16

Fixes a second startup crash in the Player Graves accessory mixin. The six-row
menu handler was an instance method aimed at a static Graves lambda, which Mixin
rejects while loading entity types. It is now static; behavior is unchanged.
Do not install beta 14 or 15.

Install on both client and server. Validation: clean build and regressions pass
except the updater test, which also fails on earlier commits in the author's macOS
environment. The native check now asserts the target lambda is static. Fixture tests
do not apply the generated mixin to real Graves classes, so in-game load and slot
recovery testing remain pending.

This is a test artifact and draft release. Auto-updaters ignore it until published
following gameplay testing.
