# Fan4Compat 0.1.0-beta.25

Targets the Mac depth-copy failure captured by beta 24: a DEPTH32F source copied
into a combined DEPTH32F_STENCIL8 portal target fails with GL_INVALID_OPERATION,
causing IP to disable nested portals.

Apple recursive Iris portal targets now use matching depth-only DEPTH32F textures
with separate stencil renderbuffers. Storage is reused and freed during native
framebuffer deletion/resize. Rejected layouts restore native packed attachments;
IP's original compatibility fallback remains intact. Other GPUs and main targets
retain native allocation. Beta 24 portal diagnostics remain enabled.

Client-only. Test with BSL: nested portal visibility, crossings, resize, shader
reload/toggle and world rejoin. Share latest.log. Mac GPU success remains unverified.

Validation: clean build, regressions, bytecode/packaging checks and native IP setup/
Minecraft framebuffer cleanup selector checks. Regression checks cover reuse,
resource cleanup, binding restoration and rejected-layout rollback.
