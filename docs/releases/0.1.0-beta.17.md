# Fan4Compat 0.1.0-beta.17

Equipped Trinkets items (for example an elytra in the cape slot) now go into your Player
Graves grave. Previously Player Graves skipped Trinkets' own death handling, so the items
stayed on your body. Trinkets rules are respected: items marked keep by the item, slot or
another mod stay equipped, vanishing-curse items are destroyed, and everything else goes
into the grave (including with keepInventory on, matching how Graves treats your inventory).
A death carrying only trinkets now creates a grave. Recovered trinkets return to your
inventory. If the grave cannot spawn, Trinkets drops items as usual.

Requires Trinkets 3.10.0 with Player Graves 1.0.0 and the existing Aether/Accessories
grave integration. No new game hooks, so no new startup risk.

Install on both client and server. Validation: clean build and regressions pass except the
updater test, which also fails on earlier commits in the author's macOS environment; the
native check against the real Graves, Trinkets, Accessories and Minecraft 1.21.1 jars passes
and now rejects the beta 14 and beta 15 startup crashes. In-game death testing is pending.

This is a test artifact and draft release. Auto-updaters ignore it until published
following gameplay testing.
