# Fan4Compat 0.1.0-beta.1

Released: 2026-10-08. First beta; runtime behavior matches alpha 41.

## Supported behavior

- TARDIS ship entry/exit, moving-ship exits, landing/recall, doorway interaction,
  ship waypoints and coordinate/scanning quality-of-life fixes.
- Point Blank 2.2.0 stale draw/animation guards and correct offhand draw routing.
- Sound Physics/IP snapshot protection and bounded cached rays without VS;
  existing ship-aware acoustic handling with supported VS.
- Optional integrations activate only for installed supported mod combinations.
  Target gameplay mods are not mandatory; MixinSquared is bundled.

See the [README](../../README.md#supported-builds) for exact versions and all
compatibility hooks. Install `Fan4Compat-0.1.0-beta.1.jar` on client and server,
replacing older Fan4Compat jars; retain original target-mod jars.

## Validation

Pack owner confirmed singleplayer core workflows and the remaining dedicated-
server, shader on/off, portal audio with/without VS and offhand gun/key checks.
Clean build, generated bytecode verification, packaging and regression tests pass.
Beta testing across normal play sessions and restarts continues before stable.

## Known limitations

Exterior ships may not render through reopened TARDIS doors before stepping out.
That feature remains on the wishlist. Create/Flywheel GPU rendering with Iris
shaders is not supplied by this addon; native fallback remains. WWOO/DH grid seams
remain unresolved and the experimental generation border stays removed.
DH double-close, Macaw model issues and accepted cosmetic warnings are unchanged.
