# Fan4Compat 0.1.0-beta.44

**Bumblezone turns shaders off.** Entering the Bumblezone (`the_bumblezone:the_bumblezone`) switches your Iris shader pack off and says "The Bumblezone is best experienced without shaders" in chat.
The shaders come back when you go to another dimension; TARDIS dimensions do not count, in either direction, so stepping into a TARDIS from the Bumblezone keeps them off. Only shaders this switch
turned off are turned back on, and shaders you switch on again yourself while inside stay on until your next visit. Leaving the world also gives them back, so they are not left off for every other world.
It uses Iris's public API, which saves Iris's setting: if the game crashes inside the Bumblezone the shaders stay off until you turn them on again.
Switch: **Bumblezone turns shaders off** (`bumblezoneShaders`, on by default, restart to change; needs Iris and the Bumblezone).

Validation: clean build, all tests (new: the switch's logic for entering, staying, TARDIS dimensions both ways, restoring, hand-enabled and already-off shaders, and leaving the world) and a native check of
every Iris API, Minecraft and Fabric member it uses against the real jars (Iris 1.8.14). The dimension id is not checked against a Bumblezone jar. Not run in game.
