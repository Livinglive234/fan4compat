# Fan4Compat 0.1.0-beta.52

**Sodium 0.8.13 and Iris 1.8.14-beta.1 with Immersive Portals and Valkyrien Skies (experimental).** Immersive Portals 6.0.6/6.0.7 and Valkyrien Skies were written for Sodium 0.6 and Iris 1.8.1. Sodium 0.8 reorganised the classes
both of them hook, so on Sodium 0.8 several of their hooks fail and the world does not load. This release carries replacements and turns the old ones off when Sodium 0.8 is installed:

- **Portal culling** (`sodiumPortalCulling`, on by default): Sodium 0.8 split `Viewport.isBoxVisible` into four methods; Fan4Compat applies Immersive Portals' extra portal culling to all four and ports Immersive Portals'
  occlusion-culling hook to `OcclusionCuller`. Immersive Portals' own two Sodium classes are cancelled.
- **Ship rendering** (`sodiumShipRendering`, on by default): Valkyrien Skies' ship drawing through Sodium (per-ship render lists, rebuild queues and the transformed draw call) is re-implemented against Sodium 0.8. Valkyrien
  Skies' two `RenderSectionManager` mixins are cancelled. A failure turns ship drawing off for the session with a warning in the log.
- **Iris 1.8.14-beta.1** is now accepted by the Iris-gated fixes (shader compile state after a failed compile, Apple GPU fixes, Distant Horizons depth fixes, Freecam with BSL). Iris 1.8.1 is still accepted.

## Heavy disclaimer: this needs an edited Immersive Portals jar and a newer Fabric Loader

- **Immersive Portals must be edited by hand.** Its `fabric.mod.json` declares `breaks` on any Sodium other than 0.6.7 and any Iris other than 1.8.1, and Fabric Loader refuses to start. Fan4Compat cannot override that, because
  the check happens before any mod code runs. Remove these two lines from the `breaks` object in `fabric.mod.json` inside the Immersive Portals jar, and nothing else:
  `"iris": ["<1.8.1", ">1.8.1"],` and `"sodium": ["<0.6.7", ">0.6.7"],`
  This is an unsupported modification of another mod's jar. Do not report problems from an edited jar to the Immersive Portals author.
- **Fabric Loader 0.20.1** is required by Sodium Extra 0.9.5.
- **Sodium Options API cannot be installed**: Sodium 0.8.13 and Reese's Sodium Options 2.2.4 both declare `breaks` on it. Mods that use it optionally lose that option page.
- Tested set: Sodium 0.8.13, Iris 1.8.14-beta.1, Sodium Extra 0.9.5, Reese's Sodium Options 2.2.4, More Culling 1.0.10, Immersive Portals 6.0.7 (edited), Valkyrien Skies `2.4.12-td.9`, Distant Horizons 3.3.3.
- **Stock Sodium 0.6.7 and Iris 1.8.1 are unchanged.** On those versions this release behaves like beta 51: the new hooks and cancellations apply only when Sodium 0.8 is installed, so you can update without editing anything. Beta 51 is no longer published.

## Validation

Clean build; all tests, including new ones for the culling helper, the ship render lists and the occlusion hook, and for the gates and cancellations; a build-time rule that mixin annotations are written with the retention Mixin
reads (a mistake there made one class fail to apply while testing); and real-jar checks of every Sodium, Valkyrien Skies, Minecraft, JOML and Immersive Portals member the new classes use. Run in game on a Mac with the set above:
the world and a singleplayer world load, portals show the other side correctly with shaders on, Distant Horizons does not overlay after a world change, a Valkyrien Skies ship draws and moves, and the End builds its shader pipeline.

**Not tested:** Windows and Linux in this exact state (the beta 52 jar with this set was run on a Windows PC only up to start-up), Sodium 0.8 versions other than 0.8.13, and long play sessions.
