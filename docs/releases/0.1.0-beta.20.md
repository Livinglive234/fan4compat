# Fan4Compat 0.1.0-beta.20

Adds temporary diagnostics for solid terrain disappearing with shaders disabled,
including when drawing Point Blank's XM3. Observes gun preparation, gun drawing,
scope-world rendering and world rendering. Logs actual OpenGL depth/stencil/color
state, Minecraft's cached values, framebuffer attachments, viewport and shader
status under `[Fan4Compat RenderDiag]`. It does not alter graphics state or consume
the GL error queue. A state difference alone does not prove a leak.

Restart with shaders off (or Iris removed), draw the XM3, switch away, then share
`latest.log`. Sampling runs at most once per second per stage, suppresses duplicate
reports and stops after 96 reports per launch. A snapshot failure disables sampling.
To disable the diagnostic hooks entirely, add JVM argument
`-Dfan4compat.renderDiagnostics=false` before launching. Existing gun fixes remain.

Requires supported Point Blank Fabric 2.2.0 for these client-only hooks; Iris,
Immersive Portals and Distant Horizons are optional. No server installation is
needed for this diagnostic feature. Other Fan4Compat features retain their existing
client/server installation requirements.

Validation: clean build, regressions, bytecode and packaging checks pass. Native
binding checks against real Point Blank and Minecraft 1.21.1 jars pass. Gameplay
and GPU confirmation remain pending. This is a test artifact and draft release;
auto-updaters ignore it until published following testing.
