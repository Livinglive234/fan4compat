# Fan4Compat 0.1.0-beta.42

Shared map: three things that were left over from beta 41. Beta 41 itself was not published, so everything in its notes ([beta 41](0.1.0-beta.41.md)) ships with this build.

**One stuck region no longer holds everything back.** The client's progress still never passes a chunk that has not been written, but a region that takes nothing for about a
minute (it cannot be loaded, or Xaero keeps refusing it) is now given up on for the session. Its chunks are recorded as *owed* instead: saved with the progress in the
client's `fan4compat/shared-map/<server>.properties` and sent in the join message, and the server sends them again however old they are, once. At most 1024 are listed per
dimension; beyond that the oldest falls back to the old behavior of holding the progress back. An owed chunk that gets written is no longer owed.

**Waiting chunks wait by region.** Chunks whose region is not ready are grouped by region. A region that turns one chunk away is not asked again for its others in the same
frame, and goes to the back of the line, so an unready region costs one attempt per round instead of one per chunk and ready regions are not starved.

**Terrain plus fluid.** Each column of a shared chunk now stores the terrain block and an optional fluid on top of it, which is how Xaero keeps water (a bed block with an overlay),
instead of a top block plus a "bed". Chunk batches are version 3; version 1 and 2 batches and region files from older builds are converted when read, so nothing stored on a
server needs erasing. Server and clients should be updated together: a beta 41 or older peer cannot read version 3 batches or the new join message, logs one warning and shares
nothing (Xaero's own map is unaffected).

Validation: clean build, all tests (new: owed chunks and their persistence, region grouping and give-up, the join message with owed chunks, version 2 batch conversion, the relay sending
owed chunks once) and the real-jar native checks for the shared map, Xaero map and Xaero sync. Not run in game.
