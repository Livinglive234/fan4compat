# Fan4Compat 0.1.0-beta.28

Reapplies Point Blank/IP-owned stencil functions after updating Minecraft's cache.
Beta 27 records reference 2 cached while the driver reports 0; a repeated cached
setter can otherwise skip correction. The owned setters now reapply the requested
function/reference/read-mask even when cached arguments are unchanged.

Also routes Point Blank's Iris glow/muzzle-flash raw stencil calls through the
existing cache/portal-ownership policy. Requires supported Point Blank and Iris
for that path; shared scope repair works without Iris. Portal guards and previous
framebuffer repairs remain intact. IP's own setters retain ownership of portal masks.

Diagnostics remain opt-in with -Dfan4compat.renderDiagnostics=true. Test XM3 held
versus unequipped and exterior camera, with shaders off and on. This targets a
captured state mismatch; complete Mac visual recovery remains unconfirmed.

Validation: clean build, cached-no-op reproduction, optional gates, bytecode and
packaging checks, and native Iris/shared stencil invocation checks.
