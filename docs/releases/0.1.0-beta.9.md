# Fan4Compat 0.1.0-beta.9

Candidate fix for Freecam LOD terrain disappearing with BSL 10.1.5 enabled.
The pack owner confirms shaders off behaves correctly; beta 8 did not resolve
BSL's independent distance discard.

Iris compilation adds a dedicated bool to the exact BSL DH terrain/water overlap
rule. Each DH draw enables the bypass only for the active Freecam in an unloaded
full-terrain chunk. Loaded terrain, disabled Freecam and portal views restore
native behavior. Other shader rules, pack files, global settings and generation
remain unchanged. Requires supported Freecam, DH 3.3.3 and Iris 1.8.1.

Validation: clean build, optional gates, native selectors, rewrite and uniform
regressions. Six actual BSL terrain/water stages (Overworld, Nether, End) parse
before and after patching with Iris's bundled GLSL parser. GPU compilation and
in-game confirmation remain pending. Test approaching distant terrain with BSL,
backing away, returning to loaded terrain and disabling Freecam.

Portal destination LOD work remains paused.
