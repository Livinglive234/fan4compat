# Fan4Compat 0.1.0-beta.15

Fixes a startup crash in beta 14. The Player Graves quick-retrieve hook used a
plain callback on a method that returns a value, so Mixin refused to apply the
Accessory Grave storage mixin and the game failed while loading entity types.
The hook now uses the value-returning callback type; no gameplay behavior changes.
Do not install beta 14.

Also includes internal cleanups (cached installed-mod lookup, simplified mixin
gating rules, precompiled shader patch patterns, identity-keyed caches).

Install on both client and server. Validation: clean build and regressions pass
except the updater test, which also fails on the unmodified previous commit in the
author's macOS environment. Native check now also asserts the hooked method's
return type. In-game verification of beta 14's slot recovery is still pending.

This is a test artifact. Auto-updaters ignore it until published
following gameplay testing.
