# Fan4Compat 0.1.0-beta.4

Released: 2026-10-08.

- Suppresses Eureka severe incompatibility notices in Immersive Portals, covering
  client and server paths that bypassed the previous warning-setting filter.
  Other mod warnings remain unchanged.
- Skips DH opaque/deferred LOD and terrain-fade rendering during portal views,
  and prevents Iris from treating the main view's DH frame as valid inside them.
  Main-view DH remains enabled. Portal views use normal terrain render distance;
  destination LOD generation/rendering is not implemented. Background generation
  and user configuration remain unchanged. Requires supported DH/IP and, for the
  shader guard, Iris; no VS requirement.
- Includes beta 2/3 dedicated-server lookup and detached TARDIS save fixes.

Install `Fan4Compat-0.1.0-beta.4.jar` on client and server, replacing older jars.
Clean build, bytecode, packaging and regression checks pass. New native selectors
verified against the supplied mod jars. Portal background visual checks with
shaders enabled/disabled, main-view LOD preservation, and server save/restart
confirmation remain pending.
