# Fan4Compat 0.1.0-beta.13

Aether accessory death drops now enter Player Graves instead of being missed by
its normal-inventory snapshot. Includes functional and cosmetic Accessories slots,
accessory-only deaths, persisted storage and both GUI/quick recovery paths.
Consumes the resolved death-drop queue only after a grave successfully spawns;
failed creation retains normal drops. Accessories decides KEEP/DESTROY and
keep-inventory behavior. Grave protection/access rules remain in effect.

Requires Aether, Accessories 1.1.0-beta.48+1.21.1 and Player Graves 1.0.0 for these
hooks; all remain optional. Install beta 13 on client and server. Quick retrieval
puts accessories in normal inventory for re-equipping. The six-row grave screen
shows more stacks when reopened after taking items; quick retrieval handles all
stored stacks. Keep Fan4Compat installed until extra grave contents are recovered.
128-stack storage limit; additional stacks drop normally.

Validation: clean build, generated bytecode/packaging/feature-link checks and
regression suite; item-conservation fixtures for spawn failures, copied snapshots,
full/partial inventory, GUI backlog and overflow. Native selectors verified against
the supplied Graves jar, Aether's bundled Accessories and Minecraft 1.21.1.
In-game death/recovery and save/restart checks remain pending.

Actions provides the test jar. This version creates a draft GitHub release;
players' automatic updaters cannot download it until the draft is published.
