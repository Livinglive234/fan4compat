# Fan4Compat 0.1.0-beta.10

Fix Jade/VS coordinate mixing and the macOS native abort in IP's portal copies.

- Jade converts ship hit/eye/camera vectors to world space inside its targeting
  calculations, preserving original block addresses and hit objects. Applies
  with supported Jade/VS, without requiring Eureka or IP.
- IP/Iris depth and color copying uses temporary framebuffer blits when the
  context lacks glCopyImageSubData. This targets the M2 Pro OpenGL 4.1 crash.
  Depth-only and packed-stencil metadata are respected. Separate read/draw
  bindings, scissor and temporary resources are restored/cleaned up on success
  and failure. Supported image-copy contexts keep the native path.

Validation: clean build, optional gates, native selectors/state APIs and fixture
regressions for coordinate conversion, original-address preservation, copy masks,
attachments, native-path bypass and state/resource restoration. Actual Mac GPU
and gameplay validation are pending. Test BSL portal crossings on Mac and Jade
on moving/rotating ships, ordinary blocks, fluids and entity targets.

No chunk loading, terrain generation or global configuration changes. Existing
Freecam/BSL fix remains; destination portal LOD work stays paused.
