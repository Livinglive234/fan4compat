# Fan4Compat 0.1.0-beta.27

Expands opt-in Point Blank diagnostics around actual deferred stencil setup/
cleanup callbacks and the IP GUI-world camera render boundary. Reports distinguish
normal, portal and GUI-camera contexts, with dimension and portal layer.

Enable `-Dfan4compat.renderDiagnostics=true`. Test drawing/aiming the XM3 and
switching away, plus the TARDIS exterior camera with the gun and another item,
with shaders off and on. Share the full latest.log.

Reports allow four distinct snapshots per stage and 96 total per launch. Native
rendering and exceptions remain; no GL state or error queue is changed. Iris/IP
hooks activate only for supported installed mods. All earlier repairs are retained;
this build adds diagnostics, not a confirmed XM3/camera fix.

Validation: clean build, budget/gate regressions, generated bytecode/packaging and
native callback static/interface/signature/finally checks.
