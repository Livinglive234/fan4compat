# Fan4Compat 0.1.0-beta.12

Automatic updates for actively developed packs, without redistributing the pack.

Install this build once on each client/server. By default it checks public GitHub
releases at startup and every 30 minutes, including prereleases, and downloads
newer compatible Fan4Compat jars in the background. Verify SHA256, mod ID, version
and Minecraft 1.21.1 metadata; stage outside mods. A JDK-only helper waits until the
current process exits, saves a verified backup and atomically replaces the original
jar for next launch. Keep exactly one mod jar. No hot reload or automatic restart.

Config: `config/fan4compat-updater.properties`: enabled, autoDownload,
allowPrereleases. Client chat and server log announce ready updates. Network or
validation failures leave the current jar installed; manually changed jars are
never overwritten. See [hosting and recovery](../automatic-updates.md).

Successful versioned main builds publish jars/checksums to public releases; beta
builds are prereleases. PRs do not publish. Existing release assets are immutable.
Gson is a verified compile-only dependency supplied by Minecraft at runtime.

Validation: clean build; release/version/channel/URL, checksum/metadata,
atomic install/backup/cleanup and failure regressions; actual standalone child
process waits while the parent is alive and installs after it is absent. No
Fabric/Gson required by the helper. Windows/macOS/container hosting and in-game
chat checks remain pending. Existing compatibility patches remain unchanged.
