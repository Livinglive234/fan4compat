# Fan4Compat 0.1.0-beta.2

Released: 2026-10-08.

Fixes a dedicated-server startup crash when TARDIS entrance portal creation
looks up Valkyrien Skies helpers. The same lookup also failed during ship waypoint
status serialization in shutdown chunk saves. Java reflection enumerated client
method signatures on the common utility class and attempted to load ClientWorld,
which is absent on a dedicated server.

Exact static helper calls now read bytecode descriptors and cache a method handle
for the requested signature, without resolving unrelated client-only overloads.
Ship behavior and optional integration gates are preserved.

Install `Fan4Compat-0.1.0-beta.2.jar` on client and server, replacing older
Fan4Compat jars. Keep original target-mod jars.

## Validation

Clean build, generated bytecode validation, packaging and existing regressions
pass. A new classloader regression reproduces the unavailable-client-overload
failure and verifies cached server calls, primitives and exception propagation.
Full-pack dedicated-server startup, portal/waypoint use, saving and restart need
in-game confirmation. Known limitations and wishlist are unchanged; see the
[release readiness document](../release-readiness.md).
