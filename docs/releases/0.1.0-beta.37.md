# Fan4Compat 0.1.0-beta.37

Adds **Xaero map shows the TARDIS exterior** (client only; Xaero's World Map 1.46.0 and Doctor Who Mod). Open the World
Map while inside a TARDIS that has landed and it opens on the exterior's dimension, centered on where the TARDIS is. In
flight, or if the exterior cannot be found, the map behaves as normal, and leaving the TARDIS puts the map back. The
switch is the one Xaero's own dimension button makes and lasts only while the map screen is open; closing it puts the map back.
Xaero's writer skips recording while the map shows another dimension, so nothing is saved into the wrong map. On by
default, with a switch in the Fan4Compat settings. Not covered: the corner minimap showing the exterior, the player marker, and following the
TARDIS during travel. In a differently scaled dimension (the Nether) the map may open off-center.

This build also contains beta 36, which was never published: **Xaero waypoint sync** (on by default; install on the
server and every client; see the beta 36 notes) and the settings switch for it.

Validation: clean build (including `logCompatibilityTest`, `tardisQolTest`, `tardisShipTest`, `shipTransitTest`, `verifyBytecode` and
`featureLinkAudit` with the real Valkyrien Skies, Immersive Portals, Doctor Who Mod 1.0.39, Accessories, Sound Physics and
BCLib jars), regressions and packaging pass; `gravesNativeCheck` (with Trinkets), `pointBlankRenderNativeCheck`,
`portalDepthDiagnosticsNativeCheck`, `configNativeCheck`, `xaeroSyncNativeCheck` and `xaeroMapNativeCheck` pass against the
real jars. `wingTrailTest` could not be run: it fails with the available Minecraft jars, identically on beta 35, so it is a
jar-setup issue and not a change in this build. `updateTest` still fails on this Mac (known temp-directory symlink issue). A fixture test covers the landed switch and camera, flight and
exit cleanup, the player's own dimension choice being left alone, the search radius and the switch.
`xaeroMapNativeCheck` verifies the hook binds to `GuiMap`'s constructor and every Xaero, Doctor Who Mod (1.0.38.4 and
1.0.39) and Minecraft member used, against the real jars. Neither Xaero feature has run in game. This is a test artifact;
auto-updaters ignore it until published.
