# Fan4Compat 0.1.0-beta.36

Adds **Xaero waypoint sync**: your Xaero's Minimap waypoints are stored on the server and follow you between PCs.
It is on by default, with a switch in the Fan4Compat settings ("Xaero waypoint sync"). Install this build on the
server and on every client; a client also needs Xaero's Minimap 26.5.0.

While you log in, the server holds your join (in the connection's configuration phase, before the world loads) and
sends the waypoint files it has for you. Your client writes the newer ones into Xaero's folder for that server and
sends back any files the server lacks, so Xaero reads up-to-date files when it starts. Edits made while playing
upload within about 30 seconds. When both PCs changed a file the newest save wins and the other copy is kept as a
backup, on the server (bounded, timestamped) and on the PC (`.fan4compat-xaero/backups/`). Limits per player: 64
files, 64 KiB per file, 256 KiB total by default (`waypointMaxBytesPerPlayer` in
`config/fan4compat-xaero.properties`, capped at 700000). Stored copies are readable by server admins, under the world
folder in `fan4compat/xaero-waypoints/`.

If anything fails, or the other side lacks the feature, the join continues (after at most 20 seconds) and Xaero uses
its local files exactly as before. No Xaero code is modified. Not synced: the world map, Xaero's `config.txt`, IPv6
or Realms servers. A waypoint deleted on one PC returns on another PC unless that file is the newest save.

From this release every feature ships enabled by default (recorded in the README, architecture guide and
`PROGRESS.md`); diagnostics and debug logging remain off unless turned on.

Validation: clean build, regressions and packaging pass, including tests of the wire format, chunk reassembly,
server store limits, folder rules and a two-PC join/edit/conflict flow. `xaeroSyncNativeCheck` verifies every Minecraft
and Fabric networking member the bridge reflects on against the real Fabric API 0.116.17 and Minecraft 1.21.1 jars.
The reflective bridge itself has not run in game or on a dedicated server. This is a test artifact; auto-updaters
ignore it until published.
