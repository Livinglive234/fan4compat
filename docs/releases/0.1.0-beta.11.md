# Fan4Compat 0.1.0-beta.11

Follow-up candidates for the remaining beta 10 Jade ray and Mac renderer fallback.

- Jade ignores stale crosshair hits beyond its targeting range before building
  its own ray. Respect eye/camera perspective, third-person offset and configured
  long reach. Preserve global crosshair state and ship block addresses.
- On Apple OpenGL only, choose IP's recursive stencil depth representation from
  the actual main depth texture: 24-bit or float32, including unsized textures
  whose component size/type must be queried. Recreate owned layer buffers when
  the representation changes; preserve native layer-count recreation. Other
  vendors and unknown formats keep native choices.

The Mac log does not report the GL error number or texture formats, so a depth
mismatch remains a candidate cause. Keep IP's error check and compatibility-mode
fallback; do not force recursion after an error. Beta 10's depth/color copy
fallback and existing Freecam/BSL support remain.

Validation: clean build, native Jade/IP selectors and field reads, optional gates,
and regressions for post-dimension stale hits, eye/camera modes, long reach,
sized/unsized depth formats, other vendors and layer/binding restoration.
Actual Mac GPU and Jade gameplay confirmation remain pending. Test Jade while
crossing TARDIS doors and BSL portal-in-portal rendering on Mac.

No chunk loading, terrain generation or global crosshair/config changes.
