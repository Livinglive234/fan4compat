# Fan4Compat 0.1.0-beta.18

Crouch-right-clicking a grave now puts equipped Trinkets items (for example the crystallite
elytra in the cape slot) back into the Trinkets slot they came from, when that slot is empty
and still accepts the item. If the slot is occupied, missing or no longer valid, or exact
inventory-layout recovery is off, the item goes to your inventory as before, and equipment you
respawned with is never overwritten. Graves created by beta 17 have no slot memory and keep
inventory recovery; new graves remember the slot, including across save and restart.

Requires Trinkets 3.10.0 with Player Graves 1.0.0 and the existing Aether/Accessories grave
integration. No new game hooks.

Install on both client and server. Validation: clean build and regressions pass except the
updater test, which also fails on earlier commits in the author's macOS environment; fixtures
cover save/reload, occupied/shrunk/invalid/opt-out fallbacks and repeat retrieval; the native
check against the real Graves, Trinkets, Accessories and Minecraft 1.21.1 jars passes. In-game
testing is pending.

This is a test artifact. Auto-updaters ignore it until published
following gameplay testing.
