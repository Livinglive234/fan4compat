# Fan4Compat 0.1.0-beta.29

Mac XM3 disappearance remains confirmed after beta 28. This build adds an opt-in
caller trace around Minecraft framebuffer binding and cached stencil setters.
Reports retain requested values, before/after references, stencil attachment bits,
FBO bindings and callers. Native operations still run once; no graphics state or
GL error queue is altered. Raw third-party GL calls are outside this trace.

Enable `-Dfan4compat.renderDiagnostics=true`, restart, and draw/unequip/redraw XM3
promptly after joining. The trace expires 45 seconds after the first gun callback
or after 96 distinct reports, whichever comes first. Include the full launch log.

No new rendering fix is claimed. Existing repairs remain. Validation includes
clean build, diagnostic expiry/dedup/query-limit regressions and native checks for
static descriptors and exception-safe wrappers. Release remains a draft.
