# Fan4Compat 0.1.0-beta.26

Restores framebuffer bindings around Point Blank's lazy scope-stencil setup.
The Mac log captures gun preparation rebinding Minecraft's framebuffer to target
0; native scope setup rebuilds the target. Both native stencil-enablement calls
now restore independent read/draw bindings, resolving recreated target IDs and
preserving unrelated shader/portal targets. Native setup and exceptions remain.

Requires supported Point Blank only. Iris/IP are optional. The beta 25 Mac portal
workaround is retained. This is a focused repair for a captured binding leak;
complete Mac XM3 terrain recovery remains unverified.

Test drawing/aiming the XM3 and switching away with BSL on and shaders off, plus
scopes and portals. Keep `-Dfan4compat.renderDiagnostics=true` and send latest.log.

Validation: clean build, binding-leak/recreated-target/failure regressions, optional
gates, bytecode/packaging checks and actual Point Blank native redirect checks.
