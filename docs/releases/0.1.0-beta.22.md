# Fan4Compat 0.1.0-beta.22

Doctor Who Mod hooks now accept versions **1.0.38.4 and newer**, including 1.0.39.
The previous baseline remains enabled. Numeric semantic-version comparison handles
later patch/minor/major versions and build metadata; older or malformed versions
and prereleases below the minimum remain excluded. Unsupported-version warnings
now report `>=1.0.38.4` rather than an exact DWM pin.

Other mod version pins and combination requirements remain unchanged. DWM model
caching still works alone; ship features still require VS and portal features
still require supported IP. Native DWM hook selectors are unchanged. Newer DWM
API changes may need separate hook updates; no 1.0.39 runtime jar was supplied
for native-binding/gameplay verification in this change.

Validation covers the minimum, 1.0.39, later numeric versions, development
prereleases/build metadata, older/malformed versions, all DWM hooks and dependency
gates. This build remains a test artifact until published.
