# Fan4Compat 0.1.0-beta.14

Crouch-right-click can now restore Aether accessories to their original accessory
and cosmetic slots when Player Graves' exact inventory-layout recovery is enabled.
Record slot names, indices and cosmetic identity from the resolved native death
drops; persist this metadata with the grave and track grave-screen paging moves.
Restore through Accessories' normal slot validation, stack limit and setter.

Occupied, removed, resized or invalid slots fall back to ordinary inventory
recovery without overwriting equipped respawn items. Include equipped stacks in
the native quick-retrieval count and complete accessory-only XP/locator cleanup.
Exact-layout opt-out still recovers into inventory. Graves created with beta 13
have no original-slot metadata and keep inventory-only accessory recovery.
Grave access/ownership, KEEP/DESTROY and keep-inventory rules remain native.

Install on both client and server. Validation: clean build and all regressions;
fixtures for identical rings in distinct slots, cosmetic separation, persisted
metadata, GUI paging/deposits, occupied/unavailable destinations, exact-layout
opt-out and repeated recovery without duplication. Native checks against supplied
Player Graves 1.0.0, Aether's bundled Accessories beta 48 and Minecraft 1.21.1 pass.
Gameplay equipment effects/client synchronization and save/restart tests pending.

This is a test artifact and draft release. Auto-updaters ignore it until published
following gameplay testing.
