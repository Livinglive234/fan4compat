# Fan4Compat 0.1.0-beta.24

Adds targeted diagnostics for shader-on nested portals failing on macOS.
`[Fan4Compat PortalDepthDiag]` records the existing depth-copy OpenGL error,
source/destination framebuffer completeness and depth/stencil representations,
GPU identity, portal layer and renderer settings. It logs one success and at
most eight failures per launch. No extra errors are consumed, no GL bindings are
changed, and IP's native compatibility fallback is preserved.

Enabled by default with supported IP/Iris; disable with
`-Dfan4compat.portalDepthDiagnostics=false`. Point Blank diagnostics remain off
by default as in beta 23. Existing rendering fixes are unchanged. Client-only;
the server does not need this diagnostic update.

Reproduce a nested portal with BSL enabled and share `latest.log`. This build
collects evidence and does not claim to fix the Mac nested-portal limitation.

Validation: regression and gate checks, generated bytecode/packaging checks, and
native IP selector/signature checks. Actual Mac GPU reproduction remains pending.
