# Fan4Compat 0.1.0-beta.5

Released: 2026-10-08.

Addresses shader-only source-world DH terrain appearing behind portals, reported
with BSL 10.1.5 despite beta 4's draw/frame guards. Iris still binds stored DH
depth samplers independently of the frame flag. Both depth getters now use an
empty far-depth sampler during portal views only. Main-view textures remain
native. The sampler is cached per Iris DH pipeline and freed on pipeline clear;
texture binding is restored after allocation, including failures.

Includes earlier beta fixes. Replace the older addon with
`Fan4Compat-0.1.0-beta.5.jar` on client and server.

Clean build and regressions cover sampler routing, nested views, reuse,
teardown/recreation and allocation cleanup with a test GL backend. Native Iris
selectors checked. Actual BSL 10.1.5 visual verification is still pending; test
both portal background and normal main-view distant terrain.
