# Fan4Compat 0.1.0-beta.23

Point Blank render diagnostics are now **off by default**. The `[Fan4Compat RenderDiag]`
observers added in beta 20 are not installed unless the JVM argument
`-Dfan4compat.renderDiagnostics=true` is added before launching. The beta 21 stencil
cache fix and the gun fixes are unaffected and always active.

No other behavior changes. Requires the same supported Point Blank and Immersive
Portals versions as beta 21. Client-only; no server update is needed.

Validation: clean build, regressions, bytecode and packaging checks pass. Tests cover
the default-off state and opting in. This build is a test artifact; auto-updaters
ignore it until published.
