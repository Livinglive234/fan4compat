# Fan4Compat 0.1.0-beta.45

**Fix for the Valkyrien Skies save message filter (beta 43 and 44).** On some log messages (for example "Thread {} stopped") the filter followed log4j's reusable log event, which is its own message, in a circle and
logged a `StackOverflowError` ("WARN StatusConsoleListener ... caught java.lang.StackOverflowError ... SaveLogFilter.noisy"). Nothing crashed, but the filter misbehaved on those messages. It now reads a
message once and never follows it further, and looks up the log4j classes and methods once instead of on every log line. Until you update, turning on **Valkyrien Skies save logging** stops the filter from being installed.

Validation: clean build and all tests. The filter test now includes the reusable event that is its own message, which overflows the stack on the beta 43 code and passes on this one. Not run on a real server.
