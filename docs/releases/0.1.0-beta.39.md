# Fan4Compat 0.1.0-beta.39

Fixes the minimap showing the **bedrock roof** when you go into a TARDIS whose exterior is in the Nether (or another dimension with
a ceiling). Xaero decides which layer to draw by scanning the real world's blocks around you for a roof. Inside the TARDIS that is
the interior, so it found none and fell back to the top-down view, and the map-dimension switch added in beta 38 forced the same
fallback. Fan4Compat now supplies the cave start itself while the exterior is shown: the exterior's own height (Y + 1) when its
dimension has a ceiling, so the minimap and World Map draw the layer at the TARDIS's level, and the normal top view for open-sky
exteriors. It uses the same "Xaero minimap and waypoints follow the TARDIS exterior" switch.

Also: when the TARDIS is on a Valkyrien Skies ship the map and minimap now use its real world position (Fan4Compat's transformed
position) instead of DWM's shipyard block address.

As before, the layer drawn is whatever the World Map has stored there. If you mapped that spot at a different cave height it may
look blank until you explore it from the outside.

Validation: clean build and regressions pass, including the location test (open-sky, ceiling, unknown-type and Nether-key cases,
flight and inactive states). `xaeroMapNativeCheck` binds all nine Xaero hooks to the real Minimap and World Map classes and checks
every member used, with Doctor Who Mod 1.0.38.4 and 1.0.39; it caught a wrong method descriptor in this change before it shipped.
Not run in game. This is a test artifact; auto-updaters ignore it until published.
