# Fan4Compat 0.1.0-beta.19

Fixes a crash when opening a Player Graves grave by right-clicking it. The game's server thread
died with a bytecode VerifyError while building the grave screen, because the hook that widens
the grave to six rows ran too early inside Graves' constructor. All such constant hooks are now
static. Crouch-right-click recovery was not affected, which is why it worked earlier. Do not
install beta 13 through 18 if you open graves by hand.

Install on both client and server. Validation: clean build and regressions pass except the
updater test, which also fails on earlier commits in the author's macOS environment; the native
check against the real Graves, Trinkets, Accessories and Minecraft 1.21.1 jars now rejects this
exact fault in the beta 18 generator and passes on this build. In-game confirmation of the grave
GUI is pending.

This is a test artifact. Auto-updaters ignore it until published
following gameplay testing.
