# Fan4Compat 0.1.0-beta.34

Maintenance build. No gameplay or rendering fix changes. The four opt-in render
diagnostics (Point Blank, stencil trace, DH, portal depth copy) now share one set of
switch lookups, one sampling gate and one set of GL query helpers, so their flags,
defaults and report limits stay in step. Flags and defaults are unchanged: render and
DH diagnostics remain off by default; the portal depth observer remains on.

Log wording changes only: diagnostic failures read "Diagnostics disabled after
observation failure", DH snapshots use `mainDepthTex`, and snapshots always include
`portalLayer`, `guiCamera` and `shaders`. Small internal cleanups to the stencil helper
and mod-gating code do not change which hooks are installed.

Validation: clean build, regressions and packaging pass; native-binding checks were not
rerun against real jars. This is a test artifact; auto-updaters ignore it until published.
