# Fan4Compat 0.1.0-beta.3

Released: 2026-10-08.

Fixes failed console chunk saves when TARDIS flight data is serialized without an
attached world. Only the world-dependent ship waypoint status refresh is skipped;
existing status and normal flight serialization are preserved. Includes beta 2’s
dedicated-server static helper lookup fix.

Install `Fan4Compat-0.1.0-beta.3.jar` on client and server, replacing older jars.
Clean build, packaging, bytecode and regressions pass, including detached TARDIS
serialization. Full-pack server save and restart testing remains pending.
