# Fan4Compat 0.1.0-beta.48

**Chest Tracker no longer shows its inventory button on screens that cannot hold items.** Chest Tracker puts its button on every container screen except the few vanilla stations on its own list, so it appeared on
Etched's etching table and settings screens, Create's filters and requesters, Waystones' menus and others. Fan4Compat now adds 30 such screens from the pack's mods to Chest Tracker's blacklist: Etched (etching table,
jukebox settings, radio, boombox, album cover), Create (blueprint, filters, factory panel item, redstone requester, stock keeper screens, linked controller, train schedule), Uncrafting Table, Accessories, the Aether (altar,
lore book), Point Blank's attachment manager, Bumblezone (briefcase, crystalline flower) and all Waystones screens. Screens that hold items in the world (the album jukebox, Create's toolbox, package port and schematic
blocks, the Aether's freezer and incubator, cooking pots, chests) keep the button. Mods that are not installed are skipped. Switch: **Chest Tracker skips non-storage screens** (`chestTrackerScreens`, on by default, restart
to change; needs Chest Tracker).

Validation: clean build, all tests (new: the blacklist registration against a stand-in of Chest Tracker's API, missing classes skipped, item-holding screens left out) and a check against the real jars that Chest Tracker's
`ScreenBlacklist.add` and all 30 listed screen classes exist (Chest Tracker 2.6.7, Etched 5.2.0, Create 6.0.10, Waystones 21.1.46, Aether 1.5.11, Bumblezone 7.17.2, Point Blank 2.2.0, Accessories beta 48, Uncrafting Table 1.5.6).
Not run in game.
